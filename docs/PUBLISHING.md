# Публикация на GitHub Pages

Нужно один раз. Дальше каждое обновление — просто `git push`.

## 1. Создай репозиторий
На github.com → **New repository**.
- Имя: `stefania-nanabo-world` (другое имя тоже подойдёт — пути в сборке относительные).
- Видимость: **Public** (на бесплатном тарифе Pages для приватных репозиториев не работает).
- Галочки «Add README / .gitignore / license» **не ставь** — в проекте они уже есть.

## 2. Отправь проект
Распакуй архив, открой терминал в папке `stefania-world`:

```bash
git remote add origin https://github.com/<твой-логин>/stefania-nanabo-world.git
git push -u origin main
```

(Репозиторий уже инициализирован, коммит есть. Если GitHub попросит пароль — нужен personal access token, а не пароль от аккаунта; в логах и чатах его не показывай.)

## 3. Включи Pages
Репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## 4. Дождись выкладки
Вкладка **Actions** → запуск «CI и публикация». Зелёный — игра опубликована. Занимает 5–10 минут (там же гоняются все тесты). Если красный — открой упавший шаг и пришли мне текст ошибки.

Адрес игры: `https://<твой-логин>.github.io/stefania-nanabo-world/`

## 5. Установи на iPhone
Открой адрес в **Safari** → «Поделиться» → «На экран „Домой“». Один раз открой с интернетом и дождись главного экрана — после этого работает офлайн.

## Обновления
1. Поменял код → `git add -A && git commit -m "..." && git push`.
2. CI соберёт и выложит новую версию.
3. На телефоне при следующем открытии появится плашка «Доступна новая версия» → «Обновить». Прогресс сохраняется.
4. Если меняешь формат сохранений — подними `SCHEMA_VERSION` и добавь миграцию (см. docs/SAVES.md). Перед крупным обновлением сохрани файл `STEFANIA_SAVE.json`.

## Если что-то не так
- **404 по адресу** — Pages ещё не включены (шаг 3) или воркфлоу не закончился.
- **Белый экран** — открой адрес именно со слешем на конце `/stefania-nanabo-world/` и обнови страницу.
- **Воркфлоу красный на «Проверка типов»** — это единственное место, где проверяются настоящие типы React; пришли ошибку, поправлю.
